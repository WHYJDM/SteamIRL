# SteamIRL

Дипломный проект: веб-приложение для поиска спортивных активностей и пользовательских спортивных локаций.

Исходные материалы находятся в двух DOCX-файлах в корне: заявление о теме и блок бизнес-анализа. Реализованы аккаунты и профили, каталог активностей, площадки с картой и списком, создание и поиск игр, участие, управление своей игрой и личная история. Добавлены предложения площадок, исправления, жалобы и модерация с аудитом решений.

## Запуск

Сгенерировать локальные секреты (файл не попадёт в Git), затем при запущенном Docker Engine выполнить:

```powershell
powershell -NoProfile -File scripts/New-LocalSecrets.ps1
docker compose up --build --wait --wait-timeout 180
```

Интерфейс: [http://localhost:8088](http://localhost:8088).

[Подробная инструкция](docs/development.md) описывает локальную разработку, миграции, тесты и диагностику.

## Для проверки БД

Публикация пока отложена по указанию владельца. Для локальной передачи подготовлен `SteamIRL-review.bundle` — Git-бандл исходников с историей; удалённая ссылка не создавалась. Его можно открыть командой `git clone ./SteamIRL-review.bundle .local/review-checkout`. В этой среде корневая `.git` доступна только на чтение, поэтому метаданные подготовленного бандла находятся в игнорируемой `.local/review-git`. Для пересборки: `powershell -NoProfile -File scripts/Save-LocalReviewBundle.ps1`.
