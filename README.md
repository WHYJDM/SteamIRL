# SteamIRL

Дипломный проект: веб-приложение для поиска спортивных активностей и пользовательских спортивных локаций.

Публичный репозиторий: [WHYJDM/SteamIRL](https://github.com/WHYJDM/SteamIRL). Workflow GitHub Actions настроен на сборку, тесты и проверку контейнерного запуска; автоматического развёртывания на сервере нет. Фактический результат последнего запуска следует проверять во вкладке Actions.

Академические исходные DOCX хранятся у автора локально и не входят в текущий набор отслеживаемых файлов. Публичные границы требований и их фактическая реализация зафиксированы в [матрице соответствия BA](docs/ba-traceability.md) и [критериях проверки](docs/assessment-requirements.md). Реализованы аккаунты и профили, каталог активностей, площадки с картой и списком, создание и поиск игр, участие, управление своей игрой и личная история. Добавлены предложения площадок, исправления, жалобы и модерация с аудитом решений.

## Запуск

Клонировать репозиторий, сгенерировать локальные секреты (файл не попадёт в Git), затем при запущенном Docker Engine выполнить:

```powershell
git clone https://github.com/WHYJDM/SteamIRL.git
Set-Location SteamIRL
powershell -NoProfile -File scripts/New-LocalSecrets.ps1
docker compose up --build --wait --wait-timeout 180
```

Интерфейс: [http://localhost:8088](http://localhost:8088).

[Подробная инструкция](docs/development.md) описывает локальную разработку, миграции, тесты и диагностику.

Web-процесс использует отдельного ограниченного пользователя PostgreSQL. Bootstrap администратора, миграции и выдача прав выполняются отдельными одноразовыми сервисами.
