- В `BA_Nikitsenkau_Aliaksei 2.docx` свойства документа содержат автора/последнего редактора и другие описательные поля. Один встроенный скриншот CCS показывает пользовательский псевдоним. Персональные данные сами по себе не объявляются запрещёнными: университетский контакт и руководитель могут быть уместны в публичном академическом документе при осознанном решении и наличии оснований. Наиболее разумно отдельно оценить необходимость каждого элемента.
