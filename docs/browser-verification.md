# Проверка интерфейса через браузер

Дата: 4 ноября 2026 года. Проверен работающий локальный сайт `http://127.0.0.1:5173` через Microsoft Edge в headless-режиме с Playwright. Проверки нажимают кнопки, заполняют формы, переходят по ссылкам и проверяют результат на странице; приложение использует живые API и PostgreSQL.

## Результат

Все девять браузерных наборов завершились успешно после исправления одной найденной ошибки. Повторно прошли **98 интеграционных тестов**, **7 frontend-тестов** и production-сборка frontend. В завершённых пользовательских сценариях не обнаружены необработанные JS-ошибки и неожиданные ответы локального API 5xx.

## Найденная и исправленная ошибка

**Открытая форма создания игры сохраняла удалённую активность.**

Воспроизведение: организатор выбирает волейбол в форме игры; модератор в другом окне одобряет исправление площадки, оставляющее только баскетбол; форма получает обновлённые данные. Браузер визуально показывал баскетбол в списке, но React сохранял прежний ID волейбола. В предпросмотре пропадало название активности; запрос использовал устаревший выбор и был бы отклонён сервером.

Исправлено в `src/SteamIRL.Web/src/sessions/NewSession.tsx`: при исчезновении выбранной активности показываются пустой обязательный выбор и предупреждение. Форма требует явно выбрать новую доступную активность; предпросмотр и отправляемые данные используют один выбор. В обработчик также добавлена проверка доступности активности.

Повторная проверка в двух окнах подтвердила: до нового выбора нажатие кнопки не отправляет POST, после выбора баскетбола игра создаётся успешно. Остальные заполненные поля остаются в форме. Проверены и визуально просмотрены снимки этого состояния на 360 и 1440 px; дополнительно проверена ширина 768 px. Горизонтальной прокрутки нет.

Снимки: `.local/screenshots/qa-activity-stale-before.png` и `qa-activity-stale-fixed-{360,768,1440}.png`.

## Условия и ограничения

- Использованы отдельные QA-аккаунты. Созданные тестовые площадки сняты через модерацию, выданные QA-роли отозваны. В публичном каталоге после проверки остались две исходные площадки.
- Основные формы и экраны проверены на ширинах 360, 768, 1440 px. Это не проверка всех устройств и браузеров.
- В одном прогоне остановился ранее запущенный Vite dev-сервер. Его перезапустили; прерванный сценарий успешно повторён, оставшаяся тестовая площадка снята. На завершении `/health/ready` отвечает `Healthy`.
- Внешние OSM-тайлы недоступны из браузера этой среды: проверены отказ и резервный интерфейс, а успешная загрузка — с тестовыми изображениями. Доступность внешнего сервиса не подтверждена.
- Проверка выполнена на локальном стеке. Docker/nginx, удалённый CI, нагрузка и реальная сеть пользователей этим прогоном не проверялись.
