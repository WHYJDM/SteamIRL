# Проверка UX-комплекта

Дата: 11 ноября 2026 года. Инструменты: Microsoft Edge / Playwright, работающий React/API/PostgreSQL для снимков, автономный HTML/JS для прототипа. Ниже инженерная проверка, **не тестирование с участниками**.

## PDF и материалы

- PDF содержит ровно **24 страницы**, совпадающие с редактируемым HTML. Проверена загрузка всех 16 изображений и отсутствие горизонтального переполнения/пересечения содержимого с колонтитулом на каждой странице.
- В PDF есть Unicode text maps, оглавление и structure tree. Это позволяет выбирать текст/ориентироваться по структуре, но не означает сертификацию PDF/UA: порядок озвучивания тегов ещё требует проверки.
- Визуально просмотрены обложка, схема сценария J1, страница снимков площадок, конфликт последнего места и протокол пользовательского теста. Исходные PNG доступны в `assets` для увеличения.
- 3 сценария связаны с UC01/UC02 и US06/13–14. Отдельно показаны 12 типов компонентов и 5 ключевых экранов; регистрация — дополнительный экран.
- Контраст вычислен для 7 пар токенов. Основной текст/фон — 13.44:1, вторичный — 5.93:1, CTA — 11.89:1, ошибка — 7.23:1. Это выборочная проверка сплошных цветов, не полный аудит.

## Живое приложение — свидетельства для скриншотов

Сняты 16 состояний: список и сетевой отказ, карточка площадки, форма Immediate, ошибка времени Planned, отказ связи, созданная игра, вступление, успех, проигрыш последнего места, исправление, отсутствие выбранной активности, Pending, решение модератора, устаревшая версия и ошибка регистрации.

Ошибка последнего места воспроизведена двумя разными браузерами: один занял место, второй подтвердил позже и получил отказ. Для конфликта исправления подготовлены две версии от одной базы; после одобрения первой вторую нельзя одобрить. Все сценарии использовали реальные ответы сервера, кроме намеренного отказа сетевого запроса. Снимки не дорисовывались.

Для S01–S03 проверены ширины **360, 390, 768, 1440 px**: 12 сочетаний без горизонтальной прокрутки. На выбранных экранах не обнаружены input/select/textarea без label/aria-name. В шапке обнаружены цели высотой 15 px, повтор карты около 22 px: они отмечены для дополнительной проверки расстояний и доработки, а не объявлены соответствующими WCAG автоматически.

Учебная площадка снята через модерацию после захвата, её активные игры отменены, временная роль QA-модератора отозвана. Непредвиденных локальных HTTP 5xx и необработанных JS-ошибок в этом прогоне нет. Внешние OSM-тайлы заблокированы сетью; карточки/список доступны, успешная внешняя доставка не утверждается. Санитизированные измерения — `interface-evidence.json`.

## Автономный прототип — 14 проверок прошли

1. Inline-ошибка количества 1–30, aria-invalid/describedby и фокус.
2. J1: сохранение ввода и успешная повторная отправка после сетевой ошибки.
3. Отказ от отмены и подтверждённая отмена игры.
4. Действующее приглашение открывается вместо скрытого дубля.
5. Planned: неверное окончание, отсутствующее время при переходе на летнее время Вильнюса и правильное отображение выбранного будущего начала после успеха.
6. J2: возврат к игре после входа, отдельное подтверждение, один отклик и выход.
7. Full: ложный успех не показан, восстановление и фильтр свободных мест.
8. Cancelled/Expired/Network не выдаются за успешное участие.
9. J3: координаты, HTTPS и обоснование, сохранение полей/чекбоксов, Pending без публикации.
10. Модерация: причина обязательна, устаревшая версия допускает только отказ.
11. Одобрение изменяет отображаемый публичный адрес.
12. Шесть экранов прототипа без горизонтальной прокрутки на четырёх ширинах.
13. Клавиатурный фокус и переход к main через skip-link.
14. PDF: число страниц, Unicode maps, outline и structure tree.

Результат скрипта — `prototype-test-results.json`. Во время автономной проверки **0 HTTP-запросов и 0 JS-ошибок**. Настройки симуляции не считаются настоящей авторизацией или серверной конкуренцией; эти свойства подтверждаются отдельно приложением/его интеграционными тестами.
