# Чек-лист доступности и UX-доработки

Дата: 11 ноября 2026 года. Цель — WCAG 2.2 AA и BA NFR07–08, без заявления о полной сертификации. Проверяемые страницы: S01 список площадок, S02 форма игры, S03 карточка игры. DOM-проверка выполнена в Edge на 360/390/768/1440 px; использованы помеченные синтетические записи.

| Проверка | Статус | Свидетельство / ограничение |
| --- | --- | --- |
| Горизонтальная прокрутка | Проверено на выборке | На 12 сочетаниях экран/ширина scrollWidth ≤ innerWidth |
| Видимые label у input/select/textarea | Проверено на выборке | Не найдено полей без label/aria-name; корректность всех текстов требует пользовательской проверки |
| Клавиатурный вход и skip-link | Инженерная проверка | Tab/Enter и ссылка пропуска проверялись браузерными сценариями проекта; в UX-прогоне дополнительно проверяется форма игры |
| Видимый фокус | Частично проверено | CSS :focus-visible: 3 px #73521b, offset 5 px; все сложные сочетания с прокруткой/перекрытием не исследованы |
| Текстовые статусы | Проверено на выборке | «Набор открыт», «Мест нет», «Отменена», «Завершена» дополняют цвет |
| Сообщения об ошибке | Есть, нужны доработки | Общие role=alert присутствуют; ошибка времени не связана с конкретным input через aria-describedby и не переводит туда фокус |
| Контраст | Измерение выбранных токенов | Основной текст, вторичный текст, CTA, ошибка и статусы вычислены по sRGB; это не аудит каждого пикселя/фона |
| Размер и расстояние целей | Требует доработки/разбора | В шапке есть ссылки высотой 15 px; кнопка повтора карты около 22 px. Для WCAG 2.5.8 нужно отдельно проверить расстояния/исключения. Целевой прототип использует кнопки/навигацию ≥44 px |
| Карта без мыши и без тайлов | Частично проверено | Клавиатурное перемещение, метки и резервный список проверены; доступность всех жестов screen reader не подтверждена |
| Live-обновления | Частично проверено | Ошибки/успехи используют alert/status; озвучивание конкретным screen reader и отсутствие лишних повторов ещё нужно проверить |
| 200% / 400% zoom и text spacing | Не подтверждено полностью | Проверены ширины; это не замена нативному zoom, text spacing и расширению текста |
| NVDA/VoiceOver | Не проведено | Требуется отдельная сессия без мыши и с проверкой объявлений ошибок/статусов |
| Доступность PDF | Частично | Экспорт с tagged/outline и selectable text; порядок чтения тегов и соответствие PDF/UA не сертифицированы |

## UX-backlog для реализации после спецификации

| ID | Приоритет | Наблюдение | Целевое поведение |
| --- | --- | --- | --- |
| UX-01 | P1 | Ошибка времени показана общим блоком внизу формы | Краткое резюме + inline-сообщение у окончания, aria-invalid/describedby, фокус на первом неверном поле |
| UX-02 | P1 | Некоторые ссылки/кнопки меньше 24 px по высоте | Навигация и основные действия ≥44 px; для исключений документировать достаточные расстояния |
| UX-03 | P1 | Вход из гостевой карточки ведёт в профиль, а не обратно в игру | После входа восстановить исходную карточку и предложить явное подтверждение; автоматически не занимать место |
| UX-04 | P2 | Создание игры на мобильной карточке может оказаться ниже длинных сведений и карты | Проверить размещение основного CTA раньше; не закрывать контент фиксированной панелью |
| UX-05 | P2 | При потере последнего места ошибка внизу просит обновить, кнопка обновления выше | Рядом с ошибкой дать «Обновить игру» / «Найти другую», сохранить отсутствие отклика у проигравшего |
| UX-06 | P2 | Обязательность полей видна не везде одинаково | Единая легенда обязательных полей, обозначение optional, постоянные ограничения рядом с вводом |

Это инженерные наблюдения/гипотезы, **не** утверждения о частоте ошибок реальных участников. В автономном UX-прототипе показаны целевые улучшения UX-01/02/03/05/06; скриншоты PDF отражают фактическое приложение. Изменения продукта этим документом не считаются реализованными.

Источники: [WCAG 2.2](https://www.w3.org/TR/WCAG22/), [ошибки 3.3.1](https://www.w3.org/WAI/WCAG22/Understanding/error-identification), [подписи 3.3.2](https://www.w3.org/WAI/WCAG22/Understanding/labels-or-instructions), [размер цели 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum). Минимум 24 CSS px предусматривает исключения, включая достаточные расстояния; 44 px в прототипе — выбранный проектный ориентир, а не подмена текста стандарта.
