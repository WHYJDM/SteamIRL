# Проверка основы проекта

Дата: 2 ноября 2026 года.

Историческое уточнение от 12 ноября 2026 года: репозиторий позднее был опубликован, и удалённый workflow запускался. Его backend на коммите `2fa8e17` завершился ошибкой изоляции тестовых БД, поэтому эта запись не должна читаться как актуальный статус CI; контейнерный job того запуска был пропущен.

## Подтверждённые проверки

| Проверка | Результат |
| --- | --- |
| Сборка .NET-решения | Успешно, без предупреждений и ошибок |
| `dotnet test` на отдельном PostgreSQL 17 | 6 тестов прошли, 0 пропущено |
| Первое применение миграции через команду приложения `--migrate` | Успешно |
| Повторная миграция | Не дублирует четыре записи каталога; проверено интеграционным тестом |
| `npm run build` | Проверка TypeScript и production-сборка Vite успешны |
| `docker compose config --quiet` | Конфигурация корректна |
| HTTP через Vite → API → PostgreSQL | Страница и readiness возвращают 200; API возвращает четыре активности, включая волейбол |

Тесты проверяют каталог после повторного применения миграций, уникальность slug, его допустимый формат, две проверки health и поведение при недоступной базе. Для PostgreSQL использован отдельный временный кластер в `.local/pgdata` на порту 55433; существующая системная база не изменялась.

## Что не проверено

Docker Engine в текущей среде недоступен. Образы не собраны, контейнерный запуск и nginx не проверены локально. В GitHub Actions добавлено задание `containers`, которое должно собрать Compose-окружение и проверить каталог через nginx после успешных тестов и сборок. Удалённый CI ещё не запускался: GitHub-репозиторий пока не подключён.

Браузерные взаимодействия и визуальная проверка на разных экранах в этой проверке не выполнялись. Frontend проверен сборкой и HTTP-запросами через dev-прокси.

Зависимости установлены из доступных локальных кешей из-за сетевых ограничений среды. В репозитории нет путей к этим кешам; обычная установка описана в [инструкции разработки](development.md).
